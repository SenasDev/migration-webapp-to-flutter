# Contributing

Contributions are welcome when they improve the migration workflow, add precise Flutter equivalents for common web patterns, or clarify verification steps.

## Guidelines

- Keep `SKILL.md` compact and LLM-first.
- Put long examples, tables, and explanations in `references/`.
- Preserve the frontmatter fields required by `skills.sh` discovery.
- Test local detection with `npx skills add . --list` before opening a PR.
